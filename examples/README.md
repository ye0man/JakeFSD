# JakeFSD Examples

Ready-to-run example projects demonstrating M1 features.

| Example | Sources | Storage | Output | What it shows |
|---|---|---|---|---|
| [`sales_report`](./sales_report) | CSV | DuckDB | HTML report | Local batch report with scheduling |
| [`api_to_sqlite`](./api_to_sqlite) | REST API | SQLite | CSV | Fetching external data and exporting |

Run any example from its directory with:

```bash
jakefsd run pipeline.yaml
```
